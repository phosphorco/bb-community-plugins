# @phosphorco/bb-inbox-rows

A small published contract for bounded Inbox row hydration. It ships schemas and byte checks (root), injected public-SDK/identity registration and caller transport (`/bb`), and real-handler conformance (`/testing`). No React or source storage.

Read [CONTRACT.md](CONTRACT.md) for ownership, wire shapes and work limits. Hosts discover via the listed plugin API and `inboxRowsV1Describe`, then create one batch client; each occurrence keeps a native-navigable fallback. Inbox owns the separately registered lazy presentation and genuine shared native body.
