Find where a plugin can add to BB before you write one. **BB Plugin Guide for Nerds** opens above your current page from **Toggle BB Plugin Guide for Nerds** in the sidebar footer.

The floating guide preserves seven annotated maps covering the app window, command palette, composer, home page, settings, Plugins page and plugin backend. Select a numbered surface to read its summary, SDK symbols and examples of plugins using it. Example names link to their plugin page when available in the installed list or catalog.

Drag the header or use the Move/Resize controls. Escape dismisses the focused inner layer before the guide. Closing the guide keeps your BB route and composer draft; reopening restores the selected guide page. Guide navigation is local to the overlay.

**Copy for agent** copies a rich reference and plain text that you can paste into the composer. The new plugin owns the reference resolver, which supplies the surface title, summary and SDK symbols as agent context. It does not provide searchable mention suggestions.

Theme and Native UI catalogs, instant page changes and a measured performance pass are planned subsequent increments.
