Open Message Rules to select a project, explicit host and absolute test directory.
Write ordinary version-1 Markdown fixtures as documented in the plugin README.
Save or discard relevant enabled drafts, then use the one Test action. Expected
rejection can be a pass; errors/unknown/stale are separate from assertion failure.
Never imply a saved test sent real messages.

Current implementation has no production dispatch hooks: full original
all-eligible-sender delivery, safe separation and consumed automatic advice remain
unproved. Do not substitute compatible prefixes/aggregate messages. Native grouping
HTTP 409 proves that route's limitation only. Live JEV requires its own credential. Without verified counts, context fit is checked by the provider under explicit engineering/call bounds. Provider rejection is unresolved potential spend, never an implicit retry; do not borrow another plugin's key or claim
injected tests establish live quality/cost. An unknown paid attempt is not replayed.

Inspect rules, fixture bytes and captured run versions before diagnosing a result.
Keep drafts on conflicts; external editors can race hash-guarded replacement.
Never treat an accepted receipt acknowledgement as agent consumption.

Group scope gates every child before expensive reads/JEV. New or migrated groups stay disabled until explicitly scoped. Save/discard group drafts before Test; group revisions freeze in a run. Current mode is preview/observe editor/tests only, no automatic live observer or message effects.
