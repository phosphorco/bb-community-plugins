## Reuse a good starting point

Choose a template below BB’s New thread composer, fill a form, inspect the destination and model, and start an ordinary thread. Personal inputs are retained separately from the native freeform composer.

For an existing destination, optionally open the complete generated request in BB’s native editor to add mentions, commands and attachments. Its visible destination and run choices are retained in the submitted launch. Native text and attachments survive reload; recheck run settings when reopening.

## Create and share

Manage templates in native **Settings → Templates**, or open the same editor from chooser **New template** / selected **Edit**. Add short or long text, URL, number, select and checkbox fields. Configure project and execution choices, then preview a title and first message with sample inputs. Save unfinished drafts and publish validated immutable revisions. Unpublishing removes a template from the chooser while retaining launch evidence in **Manage → History**.

**Remove** hides a definition permanently while preserving historical revisions and launches; removed built-ins stay removed after reload. The default destination project is saved on each template.

Definitions and saved editor drafts are shared with collaborators in the trusted workspace. Personal form drafts stay with their captured owner. Starter definitions are Feedback Session and PR Review.

## Native destinations

Use an existing project, choose one when running, or configure an enrolled host and an existing local source path for project creation. Native environment setup and permission boundaries still apply. Known target provider and model choices use BB’s catalog and block when unavailable. When the full BB editor selects a new machine, BB validates its model and permissions during admission on that machine.

## Recovery and requirements

Requires BB 0.46.1 or newer with Plugin SDK 0.6.52 support and the shared identity package. The plugin retains launch snapshots and completed project steps. An uncertain thread creation is reconciled without automatic resend; no exactly-once native creation guarantee is claimed. Native first-message authorship may show the machine/plugin; Templates separately records the captured submitting actor.
